# Restore the original portfolio visual system

## Direction

Keep the original Framer-inspired monochrome language: black surfaces, floating pill navigation, layered rounded section cards, grayscale image frames, compact badges, and a restrained sans/italic-serif type hierarchy. Do not reintroduce the green editorial redesign.

## Content structure

1. Hero: name, realistic software-engineering introduction, two clear actions, and two factual evidence cards instead of testimonials.
2. Selected projects: the original staggered gallery shape, with three verified GitHub projects and CMS-managed images. Until images are uploaded, use monochrome text compositions inside the frames.
3. About and experience: verified portrait, education, PickFrame freelance engagement, and Wesclic internship, clearly distinguished.
4. Capabilities: evidence-based technology groups and concrete project scope, using the original card treatment.
5. Contact: direct email, GitHub, and LinkedIn; no unverified client metrics, endorsements, or lead form.

## Constraints and verification

- Preserve `/admin/projects` CMS, Supabase schema, image matching, deployment configuration, and canonical domain.
- Use only the candidate profile and verified repositories for claims.
- Load project images lazily, self-host the display font, and keep motion optional for reduced-motion users.
- Build, lint touched code, compare desktop/mobile screenshots against the original deployment, and check links and CMS route.
